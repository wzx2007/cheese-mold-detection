# 02 · 数据集构建方法

数据集不是"找到"的，是"造"出来的。这一份文档说明每一层决策的依据。

## 2.2 霉菌长什么样（合成依据）

依据食品微生物学文献与权威科普，污染型霉菌在奶酪表皮上的可观测特征归纳为六条，全部在合成中实现：

| # | 外观特征 | 实现方式 |
|---|---|---|
| 1 | **簇状聚集**，不是均匀撒点 | 1–3 个菌落簇，每簇 9–32 个单菌落，簇内按高斯分布堆叠；另有 0–4 个远离中心的卫星斑点 |
| 2 | **不规则轮廓** | 角度域生成 96 维随机半径剖面，做环形（周期）平滑后映射到极角，得到 $r(\theta) = r_0\,(0.70 + 0.50\,\hat p(\theta))$ |
| 3 | **绒毛/粉末边缘** | 掩膜 = smoothstep$(r(\theta)-d)$，再乘以四层 fbm 噪声调制密度，边缘呈碎絮状 |
| 4 | **中心致密色深、外缘色浅** | 颜色按 $t = 1 - d/r(\theta)$ 在 `core → edge` 之间插值，$t^{0.75}$ 控制过渡 |
| 5 | **轻微凸起的立体感** | 以掩膜作高度场，高斯模糊后与自身求差，近似朗伯受光：$\lambda = \text{clip}(0.86 + 2.9(\text{blur}(\alpha)-\alpha),\,0.55,\,1.32)$，边缘因绒毛受光而变亮 |
| 6 | **周边"潮湿晕"** | 菌落外叠一圈模糊掩膜，压低亮度并混入灰绿色调——霉菌分泌酶使表层失水变色 |

色板（加权抽样，每张图只用一种主色，模拟单一菌种污染）：

| 编号 | 名称 | 核心色 RGB | 边缘色 RGB | 权重 |
|---|---|---|---|---|
| 1 | 灰白绒霉 *Penicillium* (white) | (210,210,198) | (238,238,231) | 0.30 |
| 2 | 橄榄绿青霉 *Penicillium* (olive) | (86,112,74) | (152,172,128) | 0.30 |
| 3 | 蓝绿青霉 *Penicillium* (blue-green) | (60,98,106) | (130,162,152) | 0.20 |
| 4 | 黑曲霉 *Aspergillus niger* | (40,40,38) | (98,100,94) | 0.12 |
| 5 | 粉红污染霉 *Fusarium*/酵母 | (148,70,78) | (198,142,142) | 0.08 |

**空间分布不是随机的**：采样权重 = 奶酪掩膜 × (0.25 + 局部纹理方差)。霉菌偏好褶皱、划痕、低洼处——这是有生物学依据的（这些位置残留水分与营养）。

## 2.3 成对采样：防止模型"抄近路"

每张原图切 2 或 4 个互不重叠的方形 crop，**其中一半合成霉菌、一半保持正常**，哪一半长霉随机决定。

这带来两个关键性质：

1. **两类来自同一批照片**——光照方向、背景材质、相机型号、拍摄距离完全一致。模型想拿高分，只能依赖局部表面证据（颜色 + 纹理 + 簇状结构），不能靠"这张图像是另一批数据"。
2. **分组划分无泄漏**——同一原图的所有 crop 永远落在训练/测试的同一侧（按 `src_id` 分组）。

## 2.4 切图的三重判据

网络图库的照片里，奶酪常常和砧板、盘子、手、包装同框，甚至只有台面。直接切图会让"发霉"样本的霉菌落在花岗岩上。因此切图位置要过三道关：

1. **掩膜覆盖率 ≥ 0.48**：`cheese_mask` 在**720 px 分辨率**下计算（关键！在 288 px 下花岗岩的颗粒会被下采样糊掉，从而被误判成光滑的奶酪表面）
2. **黄色占比 ≥ 0.32**：HSV 中 $H\in[12,45]$、$S\ge60$、$V\ge85$ 的像素比例
3. **互不重叠**：候选框之间 IoU < 0.08

最终 2165 张原图中 830 张通过（通过率 38%），产出 1684 个样本。各类目的实际产出去向：

| 类目 | 通过的原图 | 产出样本 | 说明 |
|---|---|---|---|
| hard | 300 | 610 | 硬质熟成，表皮黄、纹理清晰，掩膜最容易判对 |
| fresh | 220 | 442 | 白/浅色新鲜奶酪，黄色判据命中率低，但仍贡献了 26% 的样本 |
| washed-rind | 185 | 382 | 洗皮奶酪，表皮偏橙，掩膜稳定 |
| semi-soft | 125 | 250 | 半硬质 |
| **合计** | **830** | **1684** | 正常 842 / 发霉 842 |

## 2.5 相机成像链路仿真

对**两类图像一视同仁**地施加同一套退化——这是公平性的前提，否则模型会去学噪声而不是学霉斑。

| 步骤 | 参数 |
|---|---|
| 非均匀光照 + 暗角 | 梯度 ±20% / ±14%，暗角衰减 0–38% |
| 色温漂移 | R/B 增益 0.93–1.09 |
| 离焦 | 高斯 σ ≤ 1.15 |
| 运动模糊 | 25% 概率，核长 3–10、随机角度 |
| 相机 tone 曲线 | γ 0.90–1.14 |
| 散粒噪声 | 泊松，增益 0.7–1.7 |
| 读出噪声 | 高斯 σ 1.2–7.5 |
| JPEG 压缩 | 质量 48–94 |

这套参数来自工业相机在食品产线上的常见成像条件（低照度、需要短曝光防抖、频繁压缩传输）。**湿表面高反光**的问题在这里没有完全建模——真实刷洗后奶酪表面的镜面反射会让结构光相机整片失效，这是后续工作。

## 2.6 已知的数据缺陷（要主动说明）

1. 约 5–8% 的 crop 仍以台面/砧板为主，是掩膜误判的残留。
2. 少数样本包含手、刀具、包装边缘，构成额外的干扰因素。
3. `fresh`（白色/浅色新鲜奶酪）的通过率明显低于其他类目——黄色判据对白色表皮天然不利，所以它的原图利用率偏低；不过仍有 442 个样本（26%）进入数据集，没有被整体淘汰。
4. 合成霉菌的覆盖率分布偏窄：均值 2.81%、中位数 2.32%、10–90 分位 0.94%–5.36%，缺少"刚起霉、只有针尖大一点"的极端难例。这会让报告的准确率**偏乐观**。

改进方向：引入真实缺陷样本做 few-shot 校准；用 SAM/文本提示分割替代颜色判据做奶酪掩膜；用真实产线相机采一组标定图反推噪声参数。
